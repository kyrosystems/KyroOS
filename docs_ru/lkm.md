# Загружаемые модули ядра (LKM)

KyroOS поддерживает загружаемые модули ядра (Loadable Kernel Modules, LKM) — механизм динамической загрузки и выгрузки драйверов и кода ядра во время работы операционной системы без перезагрузки.

## Обзор

Подсистема LKM позволяет:
- Динамически загружать драйверы устройств из файлов `.ko` / `.kmod`.
- Разрешать символы ядра через глобальную таблицу экспортированных символов (`kernel_syms`).
- Выполнять динамические релокации x86_64: `R_X86_64_64`, `R_X86_64_PC32`, `R_X86_64_PLT32`, `R_X86_64_32`, `R_X86_64_32S`.
- Управлять жизненным циклом модуля через функции инициализации (`module_init`) и деинициализации (`module_exit`).
- Управлять модулями из пространства пользователя через виртуальное устройство `/dev/lkm` и утилиты `lsmod`, `insmod`, `rmmod`.

## Формат модуля

Модули компилируются как перемещаемые объектные файлы формата ELF64 (`ET_REL`):

```c
// hello.c
#include "lkm.h"

int my_init(void) {
    klog_print_str("[LKM] Hello from dynamically loaded kernel module!\n", false);
    return 0;
}

void my_exit(void) {
    klog_print_str("[LKM] Unloading kernel module!\n", false);
}

LKM_INIT(my_init);
LKM_EXIT(my_exit);
```

## Компиляция модуля

Сборка модуля производится компилятором GCC с флагами для отдельностоящего кода ядра:
```bash
gcc -m64 -mcmodel=kernel -mno-red-zone -ffreestanding -fno-pie -fno-stack-protector -c hello.c -o hello.ko
```

## Управление модулями в пространстве пользователя

В системе доступны стандартные утилиты:
- `lsmod` — вывод списка загруженных в данный момент модулей ядра, их размеров и адресов в памяти.
- `insmod /path/to/module.ko` — загрузка модуля в адресное пространство ядра и вызов функции инициализации.
- `rmmod <имя_модуля>` — вызов функции завершения модуля и освобождение выделенной под него памяти.
