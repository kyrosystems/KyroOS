# Статус TLS/HTTPS в KyroOS (честно)

**Не реализовано.** Криптомодуль ядра предоставляет только SHA-256
(`SYS_SHA256`). Для TLS 1.2/1.3 нужны: разбор X.509, обмен ключами
ECDHE/RSA, AES-GCM/ChaCha20-Poly1305, рекорд-слой и машина состояний
handshake — ничего из этого нет.

Планируемый путь — портирование проверенной библиотеки (mbedTLS/wolfSSL),
а не самописный стек. До тех пор `wget`/`curl` работают только по plain HTTP
и не должны выдавать HTTPS за рабочий. Расположение системного хранилища
доверия (`/etc/ssl/certs`) зарезервировано под будущий стек.

См. также: `abi/posix_matrix.md`.
