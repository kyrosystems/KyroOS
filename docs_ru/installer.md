# Установщик системы KyroOS (`/bin/installer`)

KyroOS содержит интерактивный пошаговый мастер установки на жесткий диск, позволяющий установить полноценную операционную систему на физические накопители или виртуальные диски гипервизоров (`/dev/sda`, `/dev/sdb`, `/dev/hda`).

## Возможности установщика

- **Обнаружение накопителей**: Автоматический поиск блочных устройств в каталоге `/dev` с определением объема диска через `ioctl(IDE_IOCTL_GET_DISK_INFO)`.
- **Разметка диска в MBR**: Создание главной загрузочной записи (Master Boot Record) и разметка основного загрузочного раздела с типом `0x83` (KyroFS/Linux native).
- **Форматирование файловой системы**: Форматирование целевого раздела файловой системой KyroFS с созданием суперблока, таблицы инодов и журнала транзакций.
- **Развертывание файлов системы**: Копирование ядра (`/boot/kernel.elf`), файлов загрузчика Limine (`BOOTX64.EFI`, `limine.conf`), всех бинарных утилит `/bin/*` и системных конфигураций `/etc/*` (`passwd`, `shadow`, `group`, `hostname`, `issue`).
- **Настройка загрузчика**: Конфигурация Limine для прямой загрузки с диска в режимах UEFI и Legacy BIOS.

## Запуск установки

Из системного командного интерпретатора KyroOS (`/bin/sh`):
```sh
installer
```

Мастер выполнит следующие шаги:
1. Запрос подтверждения целевого диска для установки.
2. Предупреждение о перезаписи существующих разделов.
3. Запись MBR и таблицы разделов.
4. Создание файловой системы KyroFS.
5. Копирование файлов ОС на диск.
6. Вывод инструкций по перезагрузке и извлечению установочного ISO-образа.
